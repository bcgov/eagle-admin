1. OCR PREVIEW

Upload a document to file it under a project and extract its text content via the eagle-demi service. The file is stored in MinIO and a staff-only document record is created, then text is extracted (OCR for scans) into searchable chunks. Supported formats: PDF, DOCX, DOC, PPTX, XLSX. Processing is asynchronous — large documents may take several minutes.
